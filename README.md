# Drake Catalog Explorer

A web application that fetches live music data for Drake using the free iTunes Search API.

## Features
* **Artist Profile:** Shows Drake's genre and verified Apple Music info.
* **Top Tracks:** Displays top songs with album artwork, song lengths, and playable audio previews.
* **Albums:** Displays Drake's discography in a clean grid with release years.

## Tech Stack
* HTML5
* CSS 
* JavaScript
